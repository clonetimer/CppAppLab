使学员从“能运行项目”走向“知道学了什么、为什么失败、如何迁移”。保留现有 W1–W9 的 23 个任务、完整双语教材、三层提示、Monaco/离线基础编辑器、CLI、应用/服务实际操作、前置依赖、源码指纹、正式验收及运行与验收分离。以 course/tasks.tsv 为唯一任务注册表，不复制权威状态。主干环境是 Ubuntu 22.04/24.04（Windows 通过 WSL2）；Windows 原生迁移暂停，PR #67 保持 Draft，不删除既有研究或重新启动迁移。实际 Windows 11 + WSL2 目标机器验收仍待用户执行；Hosted Windows 只验证启动器，不能宣称原生 C++。

## CP1 不重复建设

#73 已完成的终端空闲/运行/放大/折叠、错误摘要、当前操作 pending 反馈与双语教材保持原有行为。本轮只修改视觉层及主题适配，保留桌面源码左、课程右的熟悉顺序；窄屏保留任务在前。保留全部原有按钮、数据状态、编译诊断和教程正文。对照采用现有 CI 的 --baseline（PR base 工作树）与当前候选真实引擎，既有 4 种视口的可见阅读/编辑区断言不降级，新增主题对照、色彩与无装饰性渐变检查。不能以截图代替正式验收，不为了扩大统计数字重复加任务。

每个阶段保留真实 CI、源版本、对照证据和经验，适用矩阵通过才合并。以用户完成学习任务为目标，避免把视觉修改、基础设施或参考答案不断扩展为独立产品。P0/P1 候选不改变任何 C++ 课程源、编译工具链、接受标准、注册表或历史包。
