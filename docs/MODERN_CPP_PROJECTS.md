# CP4 第二轮：独立现代 C++ 学员工程（候选）

## 学习入口

在 Ubuntu 24.04 / WSL2 的源码构建工作台，已有 C++17 项目照常运行。若需要现代项目，自行安装可选依赖：

```bash
sudo apt-get update
sudo apt-get install g++-13 cmake libgtest-dev
```

打开 CppAppLab 网页 → 查知识 → 现代工程实践 → 选择项目 → 打开学习项目。打开后在独立编辑器中阅读只读 contract.hpp，编辑 implementation.cpp，保存并执行「正式检查（独立）」。初始代码刻意不满足完整行为合同。参考代码独立维护，仅供 CI 或显式查看，绝不自动填入学员工作区。

| 独立工程 | 标准 | 代表知识 | 固定测试 |
|---|---|---|---:|
| 采样窗口统计 | C++20 | span、ranges、可选结果、数值边界 | 7 |
| 定宽报文头解析 | C++23 | expected、错误优先级、定宽整数与字节序 | 8 |

输入均为合成教学示例。不是飞行级统计、诊断或真实遥测协议。正式测试检查接口及可观察行为，不假称强制学生使用某一种内部实现语法。

## 执行与证据边界

- 工作区 `~/cppapplab-work/.modern/<固定 ID>/implementation.cpp`（或服务配置的 workspace root 下），重开不覆盖。只有该固定文件可经浏览器修改；不接受任意路径、命令、编译器、测试筛选器。固定合同位于 course/modern_projects。
- 显式保存需携带当前源码 SHA-256，拒绝过期修订。检查在临时目录只复制保存的源快照与固定 CMake、接口、测试，版本与特性宏先检查，使用 /usr/bin/g++-13、固定标准、真实 GoogleTest/CTest。
- CTest 返回 0 且实际完整固定数量通过才记独立 PASS；源码或合同变化则旧结果不再适用。独立证据写入 last-check.json，不改变正式 23 个任务、前置依赖、经典学习记录。
- 本机 learner 源是受信任的用户代码：不是操作系统隔离沙箱，不可运行不信任的代码。仅同源 loopback + CSRF，固定项目 ID/动作，文件大小、符号链接防护、单次并发锁、进程组超时与有限日志，不能抵御任意恶意本地代码。
- 专项 CI 实际构建初始失败，代学员显式填入参考后全测试通过，重开保留源码，旧修订冲突和新编辑使 PASS 失效。Chromium 重放两套独立项目和经典历史不变；移动端截图。CI 使用参考仅验证平台行为，不代表真人完成学习。

当前是待验收开发候选；源构建网页为交付入口，现有 CLI 学员压缩包并未提供独立现代网页运行器。完整 ISO C++20/23、真实学员理解与迁移、Windows 原生及现代 Ubuntu 22.04 均未宣称支持。
