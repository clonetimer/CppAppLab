
# CppAppLab Windows x64 原生学习者包（CI 候选）

## 开始学习

1. 完整解压 ZIP。建议使用普通用户可写的英文目录，可含空格，例如 `D:\CppAppLab`；如果系统存在可验证的短文件名别名，程序也允许其他安装路径。用户名及学员工作区可以是中文。
2. 双击 `Start-CppAppLab.cmd`，在本机浏览器打开网页。保持启动窗口运行，Ctrl+C 停止服务。
3. 首次学习选择“继续学习”，完成 W1–W4。无需安装 WSL2、Ubuntu、MSYS2、Python、GCC、CMake、Ninja 或 GoogleTest；本候选将原生运行依赖随包交付。
4. W5–W9 保留教材阅读，实际运行需要 Ubuntu/WSL2。CP7-E1 的 10 组 C++20/23 固定对照实验已经实际通过 20/20；CP7-E2 原有两个现代可编辑工程已通过 15/15 项固定测试，使用随包 GCC 16.2.0；独立经典知识实验仍待验收。

**重要：** W2–W4 的正式验收包含真实文件符号链接测试。普通 Windows 账户可能需要由用户/管理员开启开发者模式或具备相应权限。启动程序只检查能力并给出提示，不会自行更改系统设置；也不会跳过测试。W1 不要求此能力。

断网时可使用内置基础编辑器。无需联网下载依赖进行基础课程构建或验收；实际完全断网的普通用户机器验收仍待补充。Windows 包路径中的工具链必须为 ASCII 路径或可验证的 ASCII 短路径；学习文件和学习记录保留中文路径。若系统临时目录不兼容，可设置 `CPPAPPLAB_NATIVE_BUILD_ROOT` 为用户可写的本地英文路径。

## 其他入口

- `Start-CppAppLab.cmd --port 8766`：使用另一回环端口。
- `Start-CppAppLab.cmd --verify-tools`：检查随包工具链的实际版本，并在临时目录中完成原生 C++17 头文件、链接和可执行文件运行探针；不改变学习进度。
- `cppapplab.cmd learn`：直接使用相同的原生 CLI。
- `Start-CppAppLab.cmd --no-browser`：只启动前台服务，手动打开终端显示的地址。

学习者工作区默认位于 `%USERPROFILE%\cppapplab-work`，进度位于 `%LOCALAPPDATA%\CppAppLab\native-windows\progress`。编译缓存不含正式学习进度；更新包不会覆盖工作区及进度。

## 包身份与再分发限制

`BUILD-INFO.txt`、`package-manifest.json` 和随归档提供的 `SHA256SUMS` 记录源码版本、Python 官方 ZIP 哈希、UCRT64 冻结的 63 项软件包版本、原始包元数据、上游实际归档 SHA-256 采集报告和逐文件哈希。CP7-D2b 已实际通过 63 个锁定归档的可信签名及 SHA-256 重放，并通过解压包回归；D3a 已采集 59 个独立签名源码归档覆盖 63 个二进制包，但公开再分发义务仍未审批。工具链许可文本保存在 toolchain 的原始目录结构；嵌入式 Python 原始许可随包保留。第三方软件精确对应源码、许可证与再分发义务仍须在公开发布前完成核查。

**本包是内部 CI 验证候选，不是正式 GitHub Release。** 普通 Windows 11 实机及真人学习评估尚未完成；正式支持声明须以最终验收为准。


## 按需进入 Linux 专项（CP7-F2/F3a）

在 W5–W9 课程点击“进入 WSL2 学习”。只有此时才检测 WSL2；需提前手动准备 Ubuntu 22.04/24.04 及 `~/work/CppAppLab` 的兼容源码构建。选择受支持的默认发行版，否则优先 24.04，再 22.04；不会自动安装、克隆或更新。进入前核验 Linux 工作台与 Windows 回环转发服务实例身份和课程目录；Linux 端若前置尚未通过，打开最早待验收课程。Windows 和 Linux 的工作区、验收记录独立，浏览器后退可返回原生工作台。真实 WSL2 实机仍待验证。


## 跨环境源码复用（CP7-F3b 已通过 CI）

在 Windows 课程信息中选择“导出 Windows 基础课程源码”，可下载当前已正式通过课程的声明源码 JSON。进入 Linux 后，在已解锁且尚未开始的基础课程的“课程信息”中选择“导入本课 Windows 源码”，选择同一文件并确认。只导入本课，已有 Linux 工作区拒绝覆盖，导入后先核对自己信任的代码，再执行真实 Linux 正式验收；前置通过后继续下一课。可重复使用同一份 JSON。文件含源代码，请自行妥善保存，不包含进度、PASS、验收证据、编译输出或用户系统路径。交换支持每课 512 KiB 源码、768 KiB 编码记录及 4 MiB 总文件；实际 WSL2 实机流程待验收。
