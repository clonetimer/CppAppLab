# W1 · First C++ Program

This is your independent learner workspace. Edit only the files named in the task card.

Run the platform check from the CppAppLab repository:

\`\`\`bash
cppapplab lesson "<this-workspace>"
cppapplab hint "<this-workspace>" 1
cppapplab check "<this-workspace>"
\`\`\`

The platform compiles the learner source with GCC and compares the program output with the fixed task contract. The local evidence file is for navigation; it is not a certificate.
