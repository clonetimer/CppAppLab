# W9-A4 渐进提示

## 提示 1 — 区分准入策略和语法

基础语法由已提供的解析器处理。先计算请求头字段数，并限制传入解析器的前缀长度。先验证一条完整请求与一条未接收完整的请求。

## 提示 2 — 保留首条消息的准确边界

接收缓冲区可能包含多条消息。只传有界前缀，成功时保留解析器给出的准确消耗字节数。若头部完整但正文未完整，可以检查声明长度，且不能返回部分请求。

## 提示 3 — 明确每个返回状态

编写构造空拒绝结果的小函数，拒绝时要求关闭连接。区分头部和正文资源超限、格式错误；仅在消息完整时检查实际解码正文长度，其他时候返回新的待接收结果。分别验证恰好达到限制与超出一个字节的边界。
