## 提示 1

保持职责分离。`Task` 拥有一条记录，并保护其不变量。`TaskManager` 拥有集合，并控制记录如何进入、离开以及在管理器之间转移。

成员 `std::vector<std::unique_ptr<Task>>` 表示每个任务只有一个所有者。需要查看任务的调用者应该获得非拥有指针或值快照，而不是该指针的所有权。

## 提示 2

深拷贝时，先预留空间，再为源管理器中的每个对象创建一个新的 `Task`。拷贝赋值时，先构造完整的临时副本，再将它的集合与目标交换。这样可以避免内存分配失败后，目标停留在只拷贝了一半的状态。

移动时，转移由 `unique_ptr` 对象组成的 vector，并显式清空源集合，让移动后的源管理器具有可预期的空状态。

## 提示 3

可以按以下顺序实现：

1. 实现 `Task` 的构造、访问器、`mark_done()` 和三个运算符。
2. 实现 TaskManager 的查找、添加、删除、获取下一个 ID 和快照。
3. 使用深拷贝和 copy-and-swap 实现拷贝构造与拷贝赋值。
4. 通过转移所有权实现移动构造与移动赋值。
5. 复用 W2 文件格式，但先解析到临时管理器中，再通过交换将其应用到当前位置。
6. 保持 CLI 简洁：它应该调用 TaskManager 的操作，而不是直接操纵所有权。
