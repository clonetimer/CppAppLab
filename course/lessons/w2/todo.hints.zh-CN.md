## 提示 1

先将 Todo 列表看作一组记录。`List` 已经是 `std::vector<Item>` 的别名。使用 vector 保留插入顺序。观察函数签名：`add`、`mark_done` 和 `remove` 应各自完成一个小操作，并返回一个 `Result`。

## 提示 2

使用标准算法，不必为每项操作编写不同的搜索循环：

- `std::max_element` 可以找到最大 ID。
- `std::find_if` 可以根据 ID 定位条目。
- `std::any_of` 可以判断标题是否包含非空白字符。
- `std::unordered_map` 可以记录加载过程中已经出现过的 ID。

加载文件时，将每一行解析到一个独立的候选 vector 中。文件尚未验证完毕时，不要修改调用者的 vector。

## 提示 3

一个健壮的实现可以分成四层：

1. 修改列表之前，先验证 ID 和标题。
2. 使用 STL 算法查找、添加、更新和删除记录。
3. 每条记录序列化为一行，并对 `\\`、制表符、换行符和回车符进行转义。加载时检查版本头和每一个字段。
4. 将完整的序列化内容写入同目录下的临时文件，再将其重命名为请求的路径。加载失败时返回错误，并保持原有内存列表不变。

使用空标题、重复 ID、无效完成标志、被截断的转义序列，以及版本头错误的文件来测试解析器。
